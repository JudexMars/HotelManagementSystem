# Демонстрационные данные

[demo-session.json](demo-session.json) содержит общий начальный набор Booking и Hotel. Он загружается профилем `demo`, включённым в Docker Compose.

| Объект | Начальное состояние |
|---|---|
| Отель Север | Номера 101, 102, 103 |
| Отель Юг | Номер 104 |
| Номер 101 | Проживание 10–13 января 2020 года, timesBooked=1 |
| Номер 103 | available=false |
| Остальные номера | timesBooked=0, доступны |
| demo-user | Владелец исторической брони |

Исторические данные позволяют проверить отчёт за прошлый период; создание новых броней в прошлом через API запрещено. Профиль `dev` дополнительно создаёт администратора. Учётные записи и сброс приведены в [README проекта](../README.md#демонстрационные-данные).

[Команда наполнения](../verification/README.md#демонстрационные-данные) создаёт будущие брони на даты через 7–10 дней от текущей UTC-даты: номер 101 получает вторую бронь, номер 104 — первую, бронь номера 102 отменяется. Итоговые timesBooked: 2, 0, 0, 1 соответственно для номеров 101–104.
